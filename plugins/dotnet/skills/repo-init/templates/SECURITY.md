# Security policy

## Supported versions

Only the latest published major version receives security fixes. Older
majors are not patched — upgrade to get a fix.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting: go to the **Security**
tab of this repository → **Report a vulnerability**. This opens a private
advisory visible only to the maintainer, and is the fastest way to get a
fix moving without disclosing the issue before a patch exists.

You should get an initial response within a few days. If a report is
confirmed, a fix is prepared privately and a GitHub Security Advisory is
published alongside the patched release, with credit to the reporter unless
you'd prefer to stay anonymous.
